# ZENVUE Store Website

## Description 
This is a responsive landing page for ZENVUE Store, built using Bootstrap 5 and custom CSS. 
It includes product cards, a hero banner with an overlay, hover animations, a contact form, and a collapsible mobile navbar.

## Features
- Fully responsive design.
- Bootstrap 5 integrrated
- Hover zoom animaion on products
- Contact form section
- Smooth scroll navigation
